# 차곡 가계부

차곡은 내 컴퓨터에서 쓰는 한국어 가계부입니다. 달력에서 수입과 지출을 기록하고, 관리비나 구독료처럼 매달 돌아오는 결제일을 확인할 수 있습니다.

- 월·주 달력과 월 전체 내역에서 거래를 조회합니다.
- 월 예산, 카테고리별 분석, 결제수단별 합계를 확인합니다.
- 반복 지출의 예정 금액과 기록 상태를 확인하고, 기존 지출을 반복 일정에 연결합니다.

## 시작하기

Node.js 22.13 이상을 설치하고, 내려받은 저장소 폴더에서 실행합니다.

```sh
npm start
```

브라우저에서 [차곡 열기](http://127.0.0.1:4173)를 누릅니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. 실행에는 별도 패키지 설치가 필요하지 않습니다. 서버는 이 컴퓨터의 `127.0.0.1`에서 열립니다.

## 데이터와 백업

첫 실행에서 빈 가계부와 `data/budget.sqlite`를 생성합니다. 차곡은 한 컴퓨터에서 사용하는 앱이며, 로그인과 기기 간 동기화 기능이 없습니다. 백업하려면 서버를 종료한 뒤 SQLite 파일을 복사합니다. 복원할 때도 서버를 종료한 상태에서 해당 파일을 교체합니다.

## 개발과 검증

```sh
npm test
npm ci
npm run test:ui
```

`npm test`는 Node.js로 실행합니다. `npm run test:ui`와 `npm run capture`는 `npm ci`로 설치되는 Playwright와 시스템에 설치된 Chrome을 사용합니다. 두 명령은 각각 별도의 임시 SQLite 파일을 열고 예시 거래를 생성합니다. 결과는 `artifacts/`에 저장합니다.

`server.mjs`는 로컬 API와 화면 파일을 제공하고, `recurring.mjs`는 반복 일정과 회차를 처리합니다. `dist/`에는 서버가 직접 제공하는 HTML, CSS, JavaScript가 들어 있습니다.
